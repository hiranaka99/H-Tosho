# About these screenshots

These screenshots show H-Tosho rendered in a browser from the actual app
interface, with isolated, fictional sample data. No personal library, account
credentials, or download history is included.

- **libraries.png** — desktop Libraries page in the dark theme.
- **metadata-preview.png** — metadata comparison in the dark theme.
- **libraries-mobile.png** — Libraries page in the dark theme at a phone viewport size.

The series, artists, cover images, counts, confidence scores, connection status,
and metadata are invented examples, not provider results. The covers are
generated by the screenshot script and do not depict any published work.

To regenerate them after interface changes, install Chromium once with
`npm exec --workspace @h-tosho/web -- playwright install chromium`, then run
`npm run screenshots` from the repository root. The script lives in
[`web/test/screenshots/readme.spec.ts`](../../web/test/screenshots/readme.spec.ts).
